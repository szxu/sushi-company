# Skills

These skills are lightweight workflow modules for any coding tool that can read
repo files and follow instructions. They are inspired by the practical parts of
`obra/superpowers`: stronger planning, test discipline, debugging discipline,
verification, and review before claiming done.

Use them when the task fits:

- `skills/core/brainstorming/SKILL.md`
- `skills/core/writing-plans/SKILL.md`
- `skills/core/test-driven-development/SKILL.md`
- `skills/core/systematic-debugging/SKILL.md`
- `skills/core/requesting-code-review/SKILL.md`
- `skills/core/verification-before-completion/SKILL.md`
- `skills/workflows/deliver-windows-build-to-wsl.md`

They are intentionally tool-agnostic. Codex, Copilot, Claude, OpenCode, Cursor,
Windsurf, or Gemini can all use the same skill files.
